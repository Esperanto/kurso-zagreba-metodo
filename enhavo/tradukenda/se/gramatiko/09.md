# Eaktodáhtolaš miella

ovdanbuktojuvvo vearbbain mas lea loahppa _**-us**_ — geavahuvvo juoidá hypotehtalaš ("would", "were to"):

- _mi kred**us**_ – Mun jáhkán, mun galggan jurddašit
- _Se mi est**us** sana, mi est**us** tre feliĉa._ – Jus livččen dearvvaš, de livččen hui ilus.

**⚠️ Várut:** guokte beali cealkagis sáhttet váldit *-us*: *se*-cealkaga ja váldocealkaga.

**💡 Muittoveahkki:** mii ollašuhttá vearbavuogádaga — *-i* (infinitiiva), *-as / -is / -os* (golbma áiggi), *-u* (gohččun), *-us* (eavttulaš). Guđa loahpa gokčet juohke vearbba.

# *Kvazaŭ*

geavahuvvo konjunkšuvdnan, ja dan čuovvu dábálaččat eavttulaš:

- _Vi sidas tie **kvazaŭ** vi estus riĉulo._ – Don čohkkát doppe dego livččet rikkis olmmoš.

Dan sáhttá maid geavahit elliptihkalaččat:

- _Vi sidas tie **kvazaŭ** riĉulo._ – Don čohkkát doppe dego (leat) rikkis.

# Suffiksa _**-ad**_

ráhkada substantiivva vearbbas, nammadettiin ieš dagu:

- *kanti* (lávlut) → _kant**ad**o_ – (lávlut)
- *suferi* (gillát) → _sufer**ad**o_ – gillát

Dat maiddái ovdanbuktá joatkkalaš dahje fas fas čađahuvvon doaimmaid:

- *rigardi* (geahččat) → _rigard**ad**i_ – joatkit geahččat, geahččat
- *demandi* (jearrat) → _demand**ad**i_ – joatkit jearrat gažaldagaid
- *legi* (lohkat) → _leg**ad**o_ – lohkan

# Suffiksa _**-ar**_

čájeha objeavttaid čoakkáldaga mii lea geahččojuvvon ollislaččat:

- *arbo* (muorra) → _arb**ar**o_ – meahcci
- *vorto* (sáni) → _vort**ar**o_ – sátnegirji
- *ŝipo* (skiipa) → _ŝip**ar**o_ – fatnasat

**💡 Muittoveahkki:** *-ar* čohkke sierra ávdnasiid ovtta jovkui:

- *arbo* (muorra) → *arbaro* (meahcci)

# Suffiksa _**-um**_

lea joker-suffiksa, mas ii leat fásta mearkkašupmi:

- *plena* (olles) → _plen**um**i_ – ollašuhttit
- *proksima* (gidde) → _proksim**um**e_ – sullii
- *suno* (beaivváš) → _sun**um**i_ – beaivváščuožžilit
- _malvarm**um**i_ – oažžut nuha

**💡 Rávvagat:** *-um* lea joker suffiksaid gaskkas, seamma ládje go *je* ([oahppu 6](/se/06/gramatiko/)) lea joker gaskal preposišuvnnaid — oahpa juohke *-um* sáni sierra.

# Dovddus osiid fas ovttastahttin

Maŋŋá oahpuin geavahit fas boares bihtáid ođđa kombinašuvnnain. Loga daid bihtáid mielde:

- *ne* + *legebla* → *nelegebla* – lohkameahttun
- *ĉirkaŭ* + *iri* → *ĉirkaŭiri* – mannat birra
- *sur* + *loko* + *-e* → *surloke* – báikkis, báikkis
- *tiu* + *tempo* + *-e* → *tiutempe* – dan áigge
