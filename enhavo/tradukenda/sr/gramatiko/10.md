# Sufiks _**-an**_

_**-an**_ označava člana, stanovnika ili osobu koja pripada nekoj grupi.

- *klubo* (klub) → _klub**an**o_ (član kluba)
- *Ameriko* (Amerika) → _amerik**an**o_ (Amerikanac)
- *sama lando* (ista zemlja) → _samland**an**o_ (zemljak)
- *sama ideo* (ista ideja) → _samide**an**o_ (istomišljenik, esperantist)

**💡 Pomoć za pamćenje:** _**-an**_ odgovara pitanju "čiji član?" ili "odakle pripada?".

# Sufiks _**-ec**_

_**-ec**_ označava apstraktno svojstvo, stanje ili kvalitet.

- *bela* (lep) → _bel**ec**o_ (lepota)
- *varma* (topao) → _varm**ec**o_ (toplota)
- *simpla* (jednostavan) → _simpl**ec**o_ (jednostavnost)
- *libera* (slobodan) → _liber**ec**o_ (sloboda)

**💡 Pomoć za pamćenje:** _**-ec**_ od prideva često pravi imenicu za osobinu.

# Sufiks _**-uj**_

_**-uj**_ može označavati posudu, drvo ili tradicionalno ime zemlje.

- *mono* (novac) → _mon**uj**o_ (novčanik)
- *cindro* (pepeo) → _cindr**uj**o_ (pepeljara)
- *pomo* (jabuka) → _pom**uj**o_ (jabuka kao drvo)
- *Francoj* (Francuzi) → _Franc**uj**o_ (Francuska)

**⚠️ Obratite pažnju:** za zemlje se danas često koristi i završetak _**-io**_, na primer *Francio*. U ovom kursu još možeš sresti tradicionalne oblike s _**-uj**_.

# Razlika između _**-ig**_ i _**-iĝ**_

Oba sufiksa već poznaješ.

- _**-ig**_ znači "učiniti da nešto postane" ili "uzrokovati"
- _**-iĝ**_ znači "postati" ili "promeniti se"

Uporedite:

- *nova* (nov) → _nov**ig**i_ (učiniti novim, obnoviti)
- *nova* (nov) → _nov**iĝ**i_ (postati nov)
- *rompi* (slomiti) → _romp**iĝ**i_ (slomiti se)
- *fermi* (zatvoriti) → _ferm**iĝ**i_ (zatvoriti se)

**⚠️ Obratite pažnju:** u srpskom se povratno "se" ponekad pojavljuje uz oba značenja. U esperantu je razlika jasna: _**-ig**_ ima uzročnika, _**-iĝ**_ ima promenu subjekta.

# Koreni u složenicama

Koreni *rilat*, *part*, *temp* i *flank* često se pojavljuju u dužim rečima.

- *rilato* (odnos) + _**-a**_ → *rilata* (povezan, odnosni)
- *parto* (deo) + _**-ig**_ + _**-i**_ → *partigi* (podeliti)
- *sama* (isti) + *tempo* (vreme) + _**-a**_ → *samtempa* (istodoban)
- *granda* (velik) + *parto* (deo) + _**-e**_ → *grandparte* (velikim delom)
- *unu* (jedan) + *flanko* (strana) + _**-a**_ → *unuflanka* (jednostran)

**💡 Pomoć za pamćenje:** poslednji koren daje glavni smer značenja, a prethodni delovi ga sužavaju.
