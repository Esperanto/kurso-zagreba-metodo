# Sufiks _**-il**_

_**-il**_ označava alat, sredstvo ili pomagalo za neku radnju.

- *tranĉi* (seći) → _tranĉ**il**o_ (nož)
- *haki* (seći) → _hak**il**o_ (sekira)
- *skribi* (pisati) → _skrib**il**o_ (pisalo)
- *timigi* (plašiti) → _timig**il**o_ (strašilo)

**💡 Pomoć za pamćenje:** _**-il**_ odgovara pitanju "čime se to radi?".

# Sufiks _**-estr**_

_**-estr**_ označava vođu, starešinu ili odgovornu osobu.

- *urbo* (grad) → _urb**estr**o_ (gradonačelnik)
- *ŝipo* (brod) → _ŝip**estr**o_ (kapetan broda)
- *lernejo* (škola) → _lernej**estr**o_ (direktor škole)

U kombinaciji s _**-ar**_ može označiti vodeću grupu.

- *urbo* (grad) + _**-estr**_ + _**-ar**_ → *urbestraro* (gradska uprava)

# Kombinovanje sufiksa

Poznati sufiksi mogu se pojaviti zajedno u jednoj reči.

- *kuiri* (kuvati) + _**-il**_ + _**-ar**_ + _**-o**_ → *kuirilaro* (kuhinjski pribor)
- *pura* (čist) + _**-ig**_ + _**-il**_ + _**-o**_ → *purigilo* (sredstvo za čišćenje)
- *luma* (svetao) + _**-ig**_ + _**-il**_ + _**-o**_ → *lumigilo* (sredstvo za osvetljenje)

**⚠️ Obratite pažnju:** čitaj sufikse redom. Svaki novi deo menja reč koju si već dobio.

# Vreme, strana i tačka kao delovi reči

Koreni *mez*, *tag*, *nokt*, *flank* i *punkt* grade vremenske i odnosne izraze. Poslednji koren obično nosi glavno značenje.

- *mezo* (sredina) + *vojo* (put) + _**-e**_ → *mezvoje* (na pola puta)
- *tago* (dan) + *fino* (kraj) + _**-e**_ → *tagfine* (na kraju dana)
- *nokto* (noć) + *labori* (raditi) → *noktlabori* (raditi noću)
- *ĉefa* (glavni) + *punkto* (tačka) → *ĉefpunkto* (glavna tačka)
- *sama* (isti) + *flanko* (strana) + _**-e**_ → *samflanke* (na istoj strani)

**💡 Pomoć za pamćenje:** _**-e**_ na kraju često pretvara celu složenicu u priloški izraz, na primer za vreme, mesto ili stranu.
